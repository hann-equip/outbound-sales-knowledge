# Instrucciones para agentes

Este repositorio documenta cómo Equip vende, posiciona y opera. No es un codebase de producto: es una knowledge base.

## Cómo usar este repositorio

1. Identifica si la tarea es de **ventas B2B**, **product marketing** o **general**.
2. Lee el `README.md` de esa carpeta.
3. Abre solo los documentos necesarios. No mezcles fuentes de otra área salvo que la tarea lo pida.
4. Si actualizas un documento, mantén el mismo idioma y el mismo nivel de detalle que el archivo original.
5. No inventes ICP, precios, clientes o mensajes. Si falta un dato, dilo y apunta el archivo donde debería vivir.

## Mapa de carpetas

| Carpeta | Usar cuando | Documentos actuales |
| --- | --- | --- |
| `b2b-sales/` | ICP, priorización de leads, research de cuentas, scoring, lookalikes | `IdealCustomerProfile.md`, `LeadPlanning.md`, `LeadScoring.md`, `TopCustomerList.md` |
| `product-marketing/` | Mensajes de producto, campañas, posicionamiento, one-pagers | Aún vacío; ver el README de la carpeta |
| `general/` | Instrucciones para agentes, glosario, procesos compartidos entre equipos | Este archivo |

## Convenciones

- Español para documentos de negocio, salvo que el archivo ya esté en otro idioma.
- Un tema por archivo. No copies el ICP dentro de marketing; enlaza a `b2b-sales/IdealCustomerProfile.md`.
- Si creas un archivo nuevo, añádelo al README de su carpeta.
